# English B1: как запустить сайт бесплатно

Сайт будет работать на двух бесплатных сервисах:
- **Supabase** хранит аккаунты, слова, домашки, материалы и файлы;
- **GitHub Pages** показывает сам сайт по адресу вида `https://ваш-ник.github.io/english/`.

Всё вместе займёт около часа. Банковская карта не нужна.

---

## Шаг 1. Supabase: база данных

1. Зайдите на **supabase.com**, нажмите **Start your project** и зарегистрируйтесь, например через GitHub или email.
2. Нажмите **New project** и заполните поля:
   - **Name:** `english`
   - **Database Password:** придумайте и сохраните где-нибудь, в работе он не понадобится
   - **Region:** выберите ближайший, например *Central EU (Frankfurt)*
   - нажмите **Create new project** и подождите 1–2 минуты.
3. Слева откройте **SQL Editor** и нажмите **New query**.
4. Откройте файл `supabase/schema.sql` из архива. Проверьте строку с email в самом начале: это адрес, с которым вы будете регистрироваться как учитель. Сейчас там `dicenkokristina@gmail.com`. Если будете использовать другой адрес, замените его.
5. Скопируйте **весь** файл в окно запроса и нажмите **Run**. Должна появиться надпись *Success. No rows returned*.
6. Отключите подтверждение почты, чтобы ученица могла войти сразу после регистрации:
   **Authentication → Sign In / Providers → Email → Confirm email** → выключить → **Save**.
   *(Бесплатный тариф отправляет всего несколько писем в час, так что лучше без подтверждения.)*
7. Скопируйте два ключа: нажмите **Connect** вверху страницы или откройте **Project Settings → API**. Вам нужны:
   - **Project URL** (вида `https://abcdxyz.supabase.co`);
   - **Publishable key** (начинается с `sb_publishable_…`). Если такого нет, берите **anon public** key.

   Оба ключа публичные, их можно хранить на GitHub. Данные защищены правилами доступа внутри базы.

## Шаг 2. Вписать ключи в сайт

Откройте `config.js` в любом текстовом редакторе и вставьте свои значения:

```js
window.APP_CONFIG = {
  SUPABASE_URL: 'https://abcdxyz.supabase.co',
  SUPABASE_ANON_KEY: 'sb_publishable_...'
};
```

Сохраните файл.

## Шаг 3. GitHub Pages: публикация сайта

1. Зарегистрируйтесь на **github.com**.
2. Справа вверху нажмите **+ → New repository**:
   - **Repository name:** `english`
   - **Public**
   - нажмите **Create repository**.
3. На странице репозитория нажмите ссылку **uploading an existing file** и перетащите в окно **все файлы и папки** из архива:
   `index.html`, `app.js`, `styles.css`, `config.js`, `README.md`, папки `vendor` и `supabase`.
   Внизу нажмите **Commit changes**.
4. Скрытую папку `.github` браузер может не перетащить, поэтому добавьте её вручную:
   **Add file → Create new file**, в поле имени введите `.github/workflows/keep-alive.yml`.
   Вставьте содержимое одноимённого файла из архива и нажмите **Commit changes**.
   Этот файл раз в 3 дня «будит» Supabase. Без него бесплатный проект засыпает после 7 дней без активности.
5. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, **Branch: main**, папку **/(root)** и нажмите **Save**.
6. Через 1–2 минуты на той же странице появится адрес сайта, например `https://ваш-ник.github.io/english/`.

## Шаг 4. Ссылки для восстановления пароля

Вернитесь в Supabase: **Authentication → URL Configuration**.
- **Site URL:** адрес вашего сайта из шага 3.6.
- **Redirect URLs → Add URL:** тот же адрес.
- **Save**.

## Шаг 5. Первый вход

1. Откройте сайт, перейдите на вкладку **Регистрация**. Там будет написано «Первая настройка: регистрация учителя».
2. Введите имя, **тот самый email из schema.sql** и пароль. Готово, вы учитель.
   После этого зарегистрироваться как учитель больше никто не сможет.
3. На главной справа есть блок **Приглашение**. Нажмите **+ Создать код**, затем **Ссылка**, и ссылка скопируется.
   Отправьте её ученице. Она откроет ссылку, код подставится сам, и останется ввести имя, email и пароль.
   Каждый код одноразовый. Для следующей ученицы создайте новый.

## Что где делается

| Раздел | Учитель | Ученица |
|---|---|---|
| **Home** | назначает урок (дата, время, тема, ссылка на звонок), создаёт коды приглашения | видит ближайший урок, дедлайны и сколько слов повторить |
| **Homework** | создаёт задание с файлами (фото, PDF, DOCX), проверяет, пишет комментарий и оценку | прикрепляет ответ, отмечает «сделано», видит проверенное |
| **Vocabulary** | создаёт топики и добавляет в них слова, видит папки ученицы (новые слова подсвечены) | создаёт свои папки, тренирует слова карточками |
| **Materials** | добавляет ссылки и файлы по группам | тоже может добавлять, а учитель это видит |
| **Progress** | ставит оценки навыков, пишет комментарий за месяц | видит слова, домашку, маршрут уроков и серию дней |

Если учениц несколько, у учителя в шапке появляется переключатель с их именами.

## Как обновить сайт

Если я пришлю исправленные файлы, откройте репозиторий на GitHub → **Add file → Upload files**, перетащите их и нажмите **Commit changes**. Через минуту сайт обновится. Данные при этом не теряются.

## Ограничения бесплатных тарифов

- Supabase Free: 500 МБ базы и 1 ГБ файлов. Для двоих этого надолго хватит, но большие видео лучше выкладывать ссылкой, а не файлом.
- Если проект всё-таки заснул (Supabase пришлёт письмо), откройте supabase.com → проект → **Restore**. Данные сохраняются.
- GitHub отключает автоматические запуски, если в репозитории 60 дней ничего не менялось. Если придёт письмо об этом, откройте вкладку **Actions** и нажмите **Enable workflow**.
- На бесплатном тарифе нет автоматических резервных копий. Раз в месяц-два сохраняйте важное: Supabase → **Table Editor** → таблица `words` (и `homework`) → **Export → CSV**.

## Если что-то не работает

- **«Сайт почти готов»** — не заполнен `config.js`.
- **«Регистрация не прошла»** — неверный или уже использованный код, либо учитель регистрируется не с тем email, что в `schema.sql`.
- **Сайт не открывается у ученицы**: проверьте, открывается ли `https://ваш-проект.supabase.co` с её интернета. Если провайдер его блокирует, напишите мне, подберём другой вариант.
